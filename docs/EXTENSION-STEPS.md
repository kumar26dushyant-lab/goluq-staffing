## Job 2 · Google Search Console and the sitemap (10 minutes)

1. Open https://search.google.com/search-console, Add property, type "Domain", enter goluq.com.
2. Copy the TXT record it shows. In Cloudflare, DNS, Add record: type TXT, name @, content the copied value, TTL Auto. Save. Back in Search Console press Verify (wait two minutes if it fails, then retry).
3. Sitemaps (left menu): enter sitemap.xml and Submit. It should report 167 URLs discovered within a day.
4. URL inspection: paste https://goluq.com/for/coaching-institutes/indore and press "Request indexing". Do the same for https://goluq.com/ceo and https://goluq.com/partner.
5. Also add goluq.com to https://www.bing.com/webmasters (Import from Google Search Console is one click) and submit the same sitemap.
